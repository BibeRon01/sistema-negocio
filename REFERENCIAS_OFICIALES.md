# Referencias oficiales verificadas

Revisión documental: 25 de julio de 2026.

Estas referencias sustentan los parámetros de ejemplo cargados para 2026. No
convierten el sistema en una herramienta de presentación fiscal ni sustituyen
la revisión de un contador o especialista de nómina.

## Nómina

- DGII — Impuesto sobre la Renta y escala para personas físicas:
  https://dgii.gov.do/cicloContribuyente/obligacionesTributarias/principalesImpuestos/Paginas/impuestoSobreRenta.aspx
- DGII — escala salarial correspondiente a 2026:
  https://ayuda.dgii.gov.do/conversations/impuesto-sobre-la-renta-isr/ca687-cul-es-la-escala-salarial-correspondiente-al-ao-2026-del-impuesto-sobre-la-renta-isr/696a664277932619036537b8
- TSS — topes de cotización del Régimen Contributivo desde febrero de 2026:
  https://tss.gob.do/tesoreria-de-la-seguridad-social-informa-nuevos-topes-de-cotizacion-para-el-regimen-contributivo/
- TSS — guía de usuario con tasas generales de cotización:
  https://www.tss.gob.do/assets/guiausuario24b.pdf
- TSS — resolución utilizada para revisar topes y vigencia:
  https://www.tss.gob.do/assets/reso01-2025.pdf

La tasa ARL no se presenta como una cifra universal. Debe configurarse por
empleado/empresa según la clasificación confirmada y se bloquea si falta.
Antes de usar otro año o una fecha anterior a la vigencia cargada, agregue y
revise una versión nueva de los parámetros.
